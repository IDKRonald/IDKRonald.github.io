# sobre mí

Soy Ronald Hernández, de Medellín, Colombia. Estudio Ingeniería de Sistemas en la Universidad Nacional de Colombia, sede Medellín, y soy tecnólogo en Análisis y Desarrollo de Software del SENA.

Me gusta construir software que resuelve problemas concretos. Mi punto de venta, PeñolinniPOS, funciona hoy en una pizzería: reemplazó las comandas en papel y aumentó la eficiencia de la operación en cerca de un 20 %.

PortónApp

en implementación

Plataforma web para la gestión de unidades residenciales, con una API REST propia y un frontend ligero sin framework.

  • API REST con Express 5 organizada en routes/, services/ y middleware/, sobre MySQL (mysql2).
  • Autenticación con JWT y refresh tokens, contraseñas con bcryptjs y manejo de cookies con cookie-parser.
  • Seguridad con helmet, cors y express-rate-limit.
  • Subida de avatares con multer, logs con morgan y un middleware de auditoría propio.
  • Scripts para inicializar, resetear y migrar la base de datos.
  • Frontend sin framework: HTML estático, CSS modular por página y JavaScript con fetch.

EasyParking

investigación · SENA

Plataforma web para automatizar y controlar parqueaderos en Guarne, Antioquia, desarrollada con Scrum en el semillero de Teleinformática del SENA.

  • Captura de placas con IA y asignación automática de celdas.
  • Modelos de machine learning (árboles de decisión con scikit-learn y agentes inteligentes con TensorFlow) para predecir la disponibilidad de espacios, con una precisión superior al 85 %.
  • Módulos de celdas, clientes, empleados, vehículos, pagos y tarifas. Registro de entradas y salidas, y acceso con usuario y contraseña.

Presentado en el XXVI Encuentro Nacional y XX Internacional de Semilleros de Investigación (RedCOLSI), Universidad de Cartagena, octubre de 2023.

Publicado en la Revista Encuentro SENNOVA del Oriente Antioqueño, 10(1), 5–18 (2024), con el título Plataforma WEB para la automatización y control integral de parqueaderos Arparking.
